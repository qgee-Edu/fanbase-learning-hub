# Fanbase Support Center: Image Specifications

A complete brief for every image referenced in the Mintlify build. Each entry maps to a file path in the project and a short description of what to create.

Two image types are referenced throughout:

- **App screenshots:** real annotated captures from the live Fanbase app. These should be sourced from current production builds and marked up in Figma with brand-consistent callouts.
- **Concept illustrations / diagrams:** brand-styled illustrations or diagrams to explain abstract concepts (payment flow, funnels, frameworks, etc).

All images should follow Fanbase's official brand colors and typography.

## Production notes

- **App screenshots** should be captured fresh from the current Fanbase 1.5 build. Several flagged items in the MDX modules note specific UI elements to verify (FB+ redesign, navigation paths, label changes). Reconcile against the live app before final capture.
- **Concept diagrams** should follow a consistent visual language across the entire Support Center: same icon set, same color treatment, same line weight.
- **Annotations** (callouts, arrows, highlight rings) should use a single, brand-consistent accent color across every annotated screenshot.
- **Image dimensions** for Mintlify: hero images render best at 1600x900 or 1200x675 (16:9). In-line annotated screenshots: 1080 wide minimum. Concept diagrams: vector SVG preferred for crisp scaling.
