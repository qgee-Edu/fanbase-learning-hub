## Local preview

```bash
npm i -g mint
mint dev
```

Opens at http://localhost:3000

## Deploy

Push to main. Mintlify auto-deploys via the GitHub integration.

## Brand alignment

Per the Fanbase Asset Creation Guidelines:

- Primary: `#9824FF` (Fanbase Violet)
- Dark accent: `#FF00D6` (Fanbase Pink)
- Background dark: `#0A0118` (Icon Gradient deep tint)
- Typography: Inter (SF Pro equivalent on Google Fonts)
- Default appearance: dark
